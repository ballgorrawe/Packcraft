# PackCraft v0.13: ด่านฝึกคลาส + โหมดปริศนา

สถานะ: แผนที่ตกลงกันแล้ว (2026-11-12) เริ่มทำหลัง deploy v0.12.0

## สิ่งที่ผู้ใช้เลือก

- ด่านฝึก: 1 ด่านต่อสาย (27 ด่าน) ร้านจัดของให้ + คำใบ้ทีละขั้น
- ปริศนา: ผสม: บทเรียนที่ออกแบบเอง + โจทย์ที่สร้างจากกระเป๋าที่บอตชนะจริง ให้ 1-3 ดาว
- รางวัล: เหรียญ + สถิติ ไม่มีผลกับเกมหลัก (สมดุลไม่เพี้ยน)

## 1. ด่านฝึกคลาส (🎓)

**เข้าเล่น:** หน้าแรก → ปุ่ม "🎓 ด่านฝึก" → เลือกคลาส → การ์ด 3 สาย (โชว์เหรียญที่ได้แล้ว) → เริ่ม

**รูปแบบ:** สั้น 5 ชั้น เลือกสายตั้งแต่ต้น (ได้เรลิกของสายเลย) ชั้น 1-4 มอนง่าย ชั้น 5 เป็น "บอสฝึก" (บอสจริงชั้น 5 ที่เบาลง) หัวใจ 3 ดวงเหมือนเกมหลัก

**เป้าหมายของทุกด่าน:** สร้าง Masterwork ของสายนั้นให้ได้ภายในคืนที่ 4 แล้วใช้มันชนะบอส

- Masterwork ทุกสาย = ของ Legendary ประจำคลาส + ของ Epic ประจำคลาส + เรลิกของสาย
  (เช่น Phoenix: ดาบตะวัน + ค้อนแมกมา + Phoenix Ember)
- ระบบคำนวณ "ต้นไม้การผสม" จากข้อมูลสูตรเอง เช่น ดาบตะวัน = ดาบเปลวเพลิง ×2 = ดาบไฟ ×4
  แล้วกระจายของลงร้านแต่ละวัน ให้ผสมทันคืนที่ 1-3 และรวมเป็น Masterwork คืนที่ 4
  จึงไม่ต้องเขียนสคริปต์เองทีละด่าน
- ทองให้พอซื้อของตามแผน + เหลือนิดหน่อยให้ลองของอื่น

**คำใบ้ทีละขั้น** (แผงแทนที่ร้านบางส่วน, ใช้กรอบสีฟ้าแบบปุ่ม 🪄):
- "ซื้อ 🗡️ ดาบไฟ 2 อัน" → ไฮไลต์การ์ดในร้าน
- "วางให้ติดกัน → ขึ้นลิงก์ทอง คืนนี้จะรวมร่างเป็น ดาบเปลวเพลิง" → กรอบสีฟ้าตรงที่ควรวาง
- อธิบายกลไกหลักของคลาส/สาย 1 บรรทัดต่อวัน (Heat, Burn, เรลิก)
- ก่อนบอส: สรุปว่ากระเป๋าตอนนี้แรงตรงไหน
- ขั้นถัดไปขึ้นเองเมื่อทำขั้นก่อนสำเร็จ

**ผลลัพธ์:** ชนะบอสฝึก = เหรียญ 🎓 ของสายนั้น · ไม่เสียหัวใจเลย = เหรียญทอง 🥇 · แพ้ = เล่นใหม่ได้ทันที

## 2. โหมดปริศนา (🧩)

**เข้าเล่น:** หน้าแรก → "🧩 ปริศนา" → รายการโจทย์แบ่งบท (โชว์ดาวที่ได้)

**รูปแบบโจทย์:** กระเป๋ารูปทรงตายตัว + ของชุดหนึ่งในกล่อง ไม่มีร้าน ไม่มีการผสม
จัดเสร็จกด "⚔️ สู้" → ดูไฟต์จริง (ใช้หน้าจอไฟต์เดิม) → ได้ดาว

**ดาว:** ชนะ = ⭐ · ชนะโดยเหลือเลือด ≥ 50% = ⭐⭐ · เหลือ ≥ 80% = ⭐⭐⭐
ใช้ปุ่มคำใบ้ 🪄 ได้ แต่ข้อนั้นได้สูงสุด ⭐⭐

**บทที่ 1 "บทเรียน" (10 ข้อ ออกแบบเอง)** แต่ละข้อสอน 1 อย่าง:
1. ของที่ติดกันบัฟกัน (หินลับมีดข้างดาบ)
2. ลิงก์ทอง (วางคู่สูตรให้ติดกัน)
3. หมุนของให้ลงช่อง
4. โล่ + หนาม กับมอนตีเร็ว
5. ซ้อนเผาไหม้ (Burn)
6. มอนต้านธาตุ (เลือกอาวุธธาตุอื่น)
7. เกราะของมอน + ตัวเจาะเกราะ
8. ชาร์จ/เร่งความเร็ว (เครื่องเป่าลม, แบตเตอรี่)
9. ช่องว่างกับอาวุธระยะไกล (หลบหลีก)
10. ใช้ไอเทมเด่นประจำคลาส

**บทที่ 2-3 "ท้าทาย" (20+ ข้อ สร้างจากกระเป๋าบอต):**
- เอากระเป๋าที่บอตชนะบอสจริง (ชั้น 10/15 จาก Bot Lab) มาสลับตำแหน่ง
- ศัตรูคือบอสตัวนั้น ปรับความแรงให้: แบบที่บอตจัด "ชนะ" แต่แบบสลับ "แพ้"
- เครื่องมือสร้างโจทย์ตรวจด้วยการจำลองไฟต์ทุกข้อ โจทย์ที่ผ่านไม่ได้จะไม่ถูกใส่
- เก็บเป็นไฟล์ data/puzzles.json (บทเรียนก็อยู่ไฟล์เดียวกัน)

## 3. ความคืบหน้าและรางวัล

- หน้าเลือกคลาส (แผงเป้าหมาย): เหรียญด่านฝึก 0/3 ของคลาสนั้น
- หน้าปริศนา: ดาวรวม เช่น ⭐ 34/90
- ไม่มีผลกับเกมหลัก

## 4. ส่วนที่ต้องสร้าง (ทางเทคนิค)

- RunState: โหมด `trial` (5 วัน, ร้านตามแผน, สายเลือกล่วงหน้า, บอสฝึกวันที่ 5) และ `puzzle` (ไม่มีร้าน/ผสม, กระเป๋าตายตัว, สู้ 1 ไฟต์)
- ตัวสร้างแผนด่านฝึก: อ่านสูตร → ต้นไม้การผสม → ของในร้านแต่ละวัน + ข้อความคำใบ้ (แปลไทย)
- เครื่องมือสร้างโจทย์ปริศนาจากกระเป๋าบอต + ตรวจด้วยการจำลอง
- หน้าจอ: เมนูหน้าแรก, เลือกด่านฝึก, แผงคำใบ้ระหว่างฝึก, รายการปริศนา, หน้าผลดาว
- เทส: ทุกด่านฝึก 27 ด่าน บอตทำตามคำใบ้แล้วได้ Masterwork และชนะบอสฝึก · ทุกโจทย์ปริศนา แบบเฉลยชนะ แบบตั้งต้นแพ้
- รีวิวด้วย Ponytail + Caveman รวมทั้ง v0.12 และ v0.13 ก่อน deploy (ผู้ใช้ขอรีวิวทีเดียว)
