# ข้อเสนอ: อีเวนต์ใหม่ + กระเป๋ามอนสเตอร์ + ของดรอปจากบอส

> สถานะ: **รอเลือก/อนุมัติ** · 2026-11-10

## 1. อีเวนต์ใหม่

**ปัญหาตอนนี้:** อีเวนต์เดิมเป็นแค่โบนัสเล็กๆ ที่ผู้เล่นไม่ต้องคิดอะไร เช่น โรงตีเหล็กให้ดาเมจ +3 ซึ่งพอถึงกลางเกมแทบไม่มีผล

**หลักใหม่:** ทุกอีเวนต์ต้องให้ผู้เล่น**ตัดสินใจ** (เลือก 1 จาก 3 หรือยอมเสียบางอย่างเพื่อได้ของ) และผลต้อง**เห็นชัดทันที**

| # | อีเวนต์ | ผู้เล่นทำอะไร | ทำไมถึงน่าสนุก |
|---|---|---|---|
| A | 🔨 **ช่างตีเหล็ก** (แทนของเดิม) | เลือกไอเทม 1 ชิ้นในกระเป๋า แล้ว**วิวัฒน์ทันที**โดยไม่ต้องหาชิ้นซ้ำ แต่ต้องจ่ายทอง | ทางลัดสู่ไอเทมระดับสูง |
| B | 🧙 **ปรมาจารย์** | เลือกพรสวรรค์ถาวร 1 จาก 3 เช่น คริ +10%, เริ่มสู้พร้อมโล่ 10, Ultimate ชาร์จเร็วขึ้น 25% | สะสมแล้วบิลด์มีเอกลักษณ์ |
| C | 🛒 **พ่อค้าเร่** | ร้านพิเศษมีของ Epic/Legendary 3 ชิ้น ราคาแพง แต่ขายของคืนได้เต็มราคา | ได้ของหายากถ้าเก็บทองไว้ |
| D | 🎰 **บ่อนพนัน** | วางเดิมพันทอง แล้วเปิดไพ่ 3 ใบ ได้ทองคืน x2, ได้ไอเทมสุ่ม หรือเสียทอง | เสี่ยงแต่ตื่นเต้น และมี animation เปิดไพ่ |
| E | ⚗️ **หม้อแปรธาตุ** | ใส่ของจากกล่อง 2 ชิ้น ได้ของระดับสูงกว่า 1 ชิ้น (สุ่มในคลาส) | เอาของเหลือมาเปลี่ยนเป็นของดี |
| F | 🗿 **แท่นบูชาต้องสาป** (แทนศาลเจ้า) | สละ Max HP 10 ถาวร หรือหัวใจ 1 ดวง เพื่อแลกของ Legendary 1 ใน 3 | ทางเลือกเสี่ยงสูงได้สูง |
| G | 🎯 **หุ่นซ้อม** | สู้กับหุ่นแบบไม่มีความเสี่ยง ไอเทมที่ทำดาเมจสูงสุดได้ดาเมจ +3 ถาวร (ยกเลิกได้) | ได้ทดสอบบิลด์ และของที่ใช้งานจริงแรงขึ้น |
| H | 📦 **หีบปริศนา** | เลือกหีบ 1 ใน 3 ที่คว่ำอยู่ ข้างในอาจเป็นไอเทม ทอง หรือคำสาปเบาๆ | สั้น สนุก |

**ที่แนะนำ:** ทำ **A, B, C, E, F, H** ก่อน และเก็บกองไฟไว้ แต่ให้ช่างตัดเย็บ (+3 ช่อง) ไปเป็นตัวเลือกหนึ่งในปรมาจารย์แทน

ทุกอีเวนต์จะเปิดเป็นหน้าเต็มจอของตัวเอง มีการ์ดให้เลือกพร้อม animation ไม่ใช่แค่ข้อความ

## 2. มอนสเตอร์มีกระเป๋าของตัวเอง

ศัตรูทุกตัวมี**กระเป๋าเล็กของตัวเอง** (เช่น 5×4 ช่อง) ใส่**ไอเทมเฉพาะมอนสเตอร์** ระหว่างสู้ไอเทมฝั่งมอนชาร์จและยิงแบบเดียวกับของเรา

### หน้าตาตอนสู้ (แนวตั้ง)
```
┌──────────────────────┐
│ 👺 Goblin  ❤️ ████     │
│ [กระเป๋ามอน 5×4 ช่อง]  │ ไอเทมมอนไล่สีชาร์จเหมือนของเรา
├──────────────────────┤
│  🤺  ⚔️ →   ← 👺     │ เวที (เตี้ยลง)
├──────────────────────┤
│ 🤺 HP ████  Ultimate  │
│ [กระเป๋าเรา]           │
└──────────────────────┘
```
- **หน้าเลือกเส้นทาง:** การ์ดศัตรูแสดงกระเป๋าย่อส่วน ให้เห็นก่อนว่ามันมีอะไร เช่น โล่ พิษ หรือฮีล ใช้วางแผนได้ (แทนระบบ Safe/Deadly ที่เอาออกไป)
- **ดาเมจของมอนมาจากไอเทม:** มอนยังมี HP พื้นฐานตามวัน แต่ไม่ตีแบบเดิมแล้ว ดาเมจทั้งหมดมาจากไอเทมในกระเป๋า
- **ไอเทมมอน (ประมาณ 25 ชิ้น):**
  - กรงเล็บ ต่อมพิษ โล่กระดูก แกนเมือก มีดโจร หมวกหนาม และอื่นๆ
  - แบ่งตามเผ่า: หนู, ก็อบลิน, โจร, สไลม์, โครงกระดูก แต่ละเผ่ามีสไตล์ของตัวเอง
- **ความยาก:** วันหลังๆ ไอเทมระดับสูงขึ้นและกระเป๋าใหญ่ขึ้น ส่วน Elite มีไอเทมเพิ่ม 1–2 ชิ้น

## 3. ของดรอปจากบอสเท่านั้น
- บอสแต่ละตัวมีไอเทมเฉพาะ 3 ชิ้น ชนะแล้ว**เลือก 1 ใน 3** ได้เลย ไม่ใช่สุ่ม
  - เช่น Magma Golem มี Magma Core, Obsidian Fist และ Lava Boots
- ไอเทมบอสแรงระดับ Legendary แต่ขนาดใหญ่ และ**ใช้ได้ทุกคลาส** เลยต้องคิดว่าจะเอาไปวางตรงไหน
- **(ตัวเลือกเสริม)** Elite มีโอกาส 15% ดรอป "ถ้วยรางวัล" เป็นไอเทมมอนสเตอร์ที่ผู้เล่นใช้ได้

## 4. ลำดับงานที่แนะนำ
1. **อีเวนต์ใหม่:** ใช้ระบบเดิมได้ ทำได้เร็วกว่า
2. **กระเป๋ามอน + ไอเทมมอน:** เปลี่ยนระบบต่อสู้และ UI หน้าสู้ทั้งหมด และต้องปรับสมดุลใหม่ด้วยบอต
3. **ของดรอปบอส:** ทำต่อจากข้อ 2

## คำถาม
1. อีเวนต์: เอาชุดที่แนะนำ (A, B, C, E, F, H) ไหม หรืออยากเลือกเอง
2. ดาเมจมอน: มาจาก**ไอเทมทั้งหมด** (แนะนำ) หรือให้ยังมีการตีพื้นฐานอยู่ด้วย
3. ให้เห็นกระเป๋ามอน**ก่อนเลือกเส้นทาง**ไหม (แนะนำให้เห็น)
4. ของบอส: **เลือก 1 จาก 3** (แนะนำ) หรือสุ่ม
